# ⚔️ Phe Phái Tranh Hùng

Game giả lập TikTok Livestream — 3 phe phái tranh đua tiêu diệt Boss.  
Xây dựng bằng **React + Vite + Pixi.js**, deploy tĩnh lên **Vercel**.

---

## 🚀 Chạy Local

### Yêu cầu
- Node.js >= 18.x
- npm >= 9.x

### Cài đặt & chạy

```bash
# 1. Clone hoặc tạo thư mục dự án
git clone <your-repo-url>
cd phe-phai-tranh-hung

# 2. Cài dependencies
npm install

# 3. Chạy development server
npm run dev
# → Mở trình duyệt tại http://localhost:5173

# 4. Build production
npm run build
# → Xuất file tĩnh vào thư mục /dist

# 5. Preview bản build
npm run preview
